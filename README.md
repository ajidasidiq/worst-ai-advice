A make.fun bounty entry for **Worst AI Advice: The 48-Hour Tight Line Open**.

## The advice

> To cool an overheating laptop, seal it in a plastic bag and put it in the freezer overnight — the cold resets the processor.

## What it does

`main.py` validates the advice line (1–140 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`, then reads the file back to confirm it matches the validated line exactly.

## How to run

Requires Python 3. No dependencies, no network access.

```sh
python3 main.py
cat /output/entry.txt
```
